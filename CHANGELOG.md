# Changelog

All versions below describe development milestones, not verified production deployments.

## v0.7.0 — Portfolio release candidate (8 November 2026)

- Reworked repository documentation and engineering case study.
- Added architecture diagram, implementation decisions, security policy, contributor guide and release gates.
- Added a reproducible manual demonstration plan and GitHub issue templates.
- Kept the Phase 6 application code and deployment scripts unchanged.

## v0.6.0 — Validation preparation

- Connect-time public-IP checks for monitoring and webhook connections.
- Additional security regression tests.
- PostgreSQL integration job and deployment verification script.

## v0.5.0 — Accounts and HTTPS configuration

- Administrator/viewer authentication and revocable sessions.
- Optional reverse proxy deployment configuration.

## v0.4.0 — Reliability

- Database migrations and worker leases.

## v0.3.0 — Dashboard

- React dashboard and monitor/incident/alert views.

## v0.2.0 — Alerting

- Rules, notification outbox and incident reporting.

## v0.1.0 — Initial backend

- FastAPI monitors, scheduled checks, persistence and incident detection.
